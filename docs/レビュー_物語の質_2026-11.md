## 1. 弱い点と、原因と思われるプロンプト上の箇所

### 1.1 展開の停滞——30 回で「見学の3日間」から出ない（A）

A は 30 回・約 1.2 万字で、**入部するかどうかを決めないまま、ドームへ行っては帰る**を繰り返す。約束した観測は 30 回目でもまだ始まらず（A-S6-T30 の最後が「……春の大曲線は、どの辺りですか」）、エピローグの1文目で片づく。

| 場所 | 起きていること |
|---|---|
| A-S2-T7〜T10 | ドームを出て坂を下りるだけで 4 回。毎回「立ち止まる／振り返る／決めない」で終わる（T8「もう一度だけ振り返った」→ T9「もう一度だけ校舎の屋上を振り返った」→ T10「坂の途中で、すずは立ち止まった」） |
| A-S4-T17〜T19 | 一人で椅子に座って星座早見盤を回すだけで 3 回 |
| A-S6 導入〜T30 | 家を出てからスリットを開けるまでに 6 回（門・通路・階段・扉・スリットに 1 回ずつ） |
| E-S3-T14・T15 | GLM でも同じ。2 回続けて「書けば証拠ではなくなる気がした。書かなければ……」で止まる |

毎回の終わりが**小さな引き**になっている: 「足音は途中で止まった」（A-S4 導入）「扉が静かに開かれた」（A-S3-T11）「気づいたのは、そのときだ」（A-S4-T19）。400〜500 字ごとに引きが来るので、読む側は引きに慣れてしまう。

B では引きが**空振り**になる: レオンが海に何かを見る →「いや……何でもない。気のせいだろう」が B-S1-T5・B-S3-T13・T14 の 3 回。謎の船は次の回で「昨夜の嵐でどこかへ去ったらしい」（B-S2-T9）。「気のせい」は本文に 4 回出る。

**原因と思われる箇所** — `buildSystemPrompt` の文体ルール（`prompts.ts` 228〜235 行）:

```
- 1回の応答で1〜3段落。情景→会話→展開、と流れを作り、物語を前へ進めてください。
- 場面の終わりに、続きが気になる引きや${heroName}が行動したくなる余白を残してください。
- ${heroName}（ユーザー）の心情や決断を勝手に断定しすぎず、選択の余地を残してください。
- ユーザー入力は物語への介入・行動として自然に地の文へ取り込んでください。メタ発言は避けてください。
```

2〜4 行目は**利用者が主人公として行動を入力する**作りだった頃の文面で、いまの読者モデル（`決定記録.md` §1: 入力はすべて書き手への指示・利用者は住人を演じない）と食い違っている。主操作が「続ける」になった今、「主人公に決めさせるな・余白を残せ」と毎回言えば、**誰も決めない物語**になる。「（ユーザー）」という括弧書きも、中心人物を利用者の分身として扱わせる。
加えて、毎ターン末尾に付く深さ0の再掲（346 行「地の文とセリフ「」を織り交ぜて1〜3段落」）が、1 回の単位を小さく保たせている（A の平均 394 字／回）。

| A 第4章 | 題は「5月13日 夕方：下校途中の出会い」。本文は「翌日、午後の日差しが……」＝作中では3日目。しかも候補の筋（坂道で東雲に会う）は書かれず、また階段から始まる。「昨日は東雲にも真木にも会ったけれど」は前章（東雲は不在）と矛盾 |
| A 第5章 | 題は「5月14日 夕方」。本文は「翌日の放課後」＝作中4日目 |

A では作中の日付が 4 日進むあいだに、記録上の `now` は 5月13日 → 5月14日 の 1 日しか進まない。そのため締切（「五月の終わり」に名簿を提出）は 30 回のあいだ一度も前景に出ず、開始時の予定 2 件は最後まで未消化のまま残る。

**原因と思われる箇所**（3つが組み合わさっている）:

1. `reviewSystem` の次シーン候補（836・851 行）— 候補の note に「時・場所」を書かせるので、候補が「翌日放課後、……」と**先の時刻を含む**。一方で 851 行の「【次シーンの時間】があればその時刻にふさわしい状況で書く（直前の続きをそのまま続けない）」が指す【次シーンの時間】は、いまはどこからも渡されていない（`store.ts` 2914 行のコメントのとおり、時刻は T に任せた）。結果、「直前の続きをそのまま続けない」も効いていない
2. `trackerSystem`（797 行）— `now` は「このシーンが終わった時点」。次の章がいつ始まるかは知らない。さらに「時間が動いていなければ与えられた現在をそのまま返す」ので、本文が「翌日の放課後」と書いていても、与えられた「5月13日」に寄せて「5月13日 夕方」と返した（A 第3章のレビュー）
3. `buildSystemPrompt` の【時間】（110〜116 行）— 「現在は「5月13日 放課後」です」と言い切る。その直前の【現在の場面】は「翌日放課後、……」。**同じ system の中で2つの時刻が並ぶ**。モデルは場面メモに従い、記録の時計だけが取り残される
4. `SCENE_START_PROMPT`（613 行）「情景の導入から自然に書き始めてください」— 毎章、そこへ**向かう**ところ（階段・扉の前）から書き始める型を作っている

### 1.5 レビューが「その場のふるまい」を設定へ書き戻し、停滞を固める

A の `characterGrowth`（承認されると【登場人物】の「これまでの展開で判明した設定」に常設される）:

- 第1章・すず「……古い観測ノートに感動する**感受性の高さが明らかになった**」
- 第2章・東雲「相手に委ねることで自主性を促し、結果を急がない**指導者としての側面が強調された**」
- 第4章・東雲「……自主性を促す指導者としての側面が**さらに強調された**」
- B 第1章・陽菜「灯台守としての責任感が強く……」（人格欄の言い換え）

どれも「新しく分かった事実」ではなく、**その章の行動の要約か人物評**。これが定義に積まれ、関係性の記述（A・東雲 → すず「来るか来ないかを自由に選ばせようとしている」が 3 章続けてほぼ同文）と合わせて毎ターン system に入る（関係性の記述は第2章と第4章でほぼ同文、第5章も同じ結び）。本文では東雲の「来たくなったら来て」「持ってていいよ」「来られなかったら、それはそれで」型のセリフが 5 つのブロックに出る（A-S2-T6・T7・A-S4-T16・A-S5-T24・エピローグ）。**状態機械が、最初の章の調子を固定する側に働いている。**

`worldGrowth` も同じで、「星座早見盤: プラスチック製の安物で縁が割れているが……」（A 第2章）のような**本文の描写の写し**がロアになり、キーワードが出るたびに深さ3へ戻ってきて、同じ描写（縁の割れ目）を再生産する。

**原因と思われる箇所** — `reviewSystem`（837・854 行）:

```
"characterGrowth": [ {"name":"キャラ名","addition":"今回の展開で新たに判明/深化した性格・背景を一文で"} ]
- characterGrowth / worldGrowth は、既存設定に無い"新しく分かったこと"のみ。無ければ空配列。
```

「深化した性格」が人物評を許している。レビューには人格欄しか渡らない（`store.ts` 2886〜2893 行。口調・セリフ例は渡らない）ので、「既存設定に無い」の判定も甘くなる。

### 1.6 説明過多と視点のぶれ

- **仕草の意味を地の文が解説する**: 「この人は、それを待っている。」（A-S2-T6）／「それは、自分がここにいてもいいと言われているのと同じだった。」（A-S4-T17）／「東雲先輩とは違う距離感で、この場所に関わっている人がいるのだと知った。」（A-S3-T14）。最後の例の「距離感」は関係性の次元名「距離」と `CONSEQUENCE_CLAUSE`（26 行「態度・口調・距離感」）の語がそのまま地の文に出たもの
- **「〜がうかがえた」「〜を感じさせた」で人物を説明する**: 「子供の頃から両親の手伝いをしてきたことがうかがえた」（B-S1-T2）「長年の経験を感じさせた」（B-S3-T12）
- **中心人物以外の内心へ入る**: 中心は陽菜なのに「彼の直感が警鐘を鳴らしていた」（B-S1-T5）「レオンは……傷跡があることに気づいた」（B-S1-T1）

### 1.7 起案（一行から始める）の出来

## 5. 上位3案の読み比べ手順

`実験_対照読み比べ.md` と同じ形（材料 2 本・読者への渡し方・質問票・判定・やらないこと）。**読ませる・判定するのは人間**で、AI が用意するのは材料作りの道具まで。3つとも次は共通。

- 素材はサンプル「霧坂高校 天文部」、モデルと温度は A・B で同じ（OpenRouter の同一 id・0.9）、同じ日に作る
- **A＝変更前（その時点の `main`）、B＝その案だけを入れたもの**。違いはその案の文面だけにする
- 作り方はアプリ（変更前後のビルドを 2 つ用意する）でも、`scripts/out/review-2026-11/sim.mjs`（今回の再現スクリプト。`--repo` に渡すフォルダを変えれば、変更前後を同じ手順で回せる）でもよい。スクリプトで作る場合は §0.2 の「アプリとの違い」が両方に同じだけ掛かる
- 遊び方の決まりは `実験_対照読み比べ.md` §1 と同じ（入力欄に何も書かない・〈展開を選ぶ〉等を使わない・レビューは編集せず承認・次の章は先頭の候補）
- 渡す前に、章の見出しと出典行を消し、「作品1」「作品2」とだけ札を付ける。どちらが変更後かは言わない。読者ごとにコインで順を決める
- 読者は**3人以上**、作者以外。記録するのは 読者 id／作品1＝A か B か／回答／読了か途中か
- 結果（日付・モデル・人数・判定の設問の内訳）を `決定記録.md` に 1 行追記。本文と回答は `scripts/out/` に置く
- **やらないこと**: 判定 LLM による評価／読者への誘導／3人未満での判定／2 案を同時に入れた材料での比較

### 5.1 案1（文体ルール）

**材料**: 「続ける」**15 回**・5 回ごとに章を閉じる（3 章）。約 6,000〜8,000 字ずつ、読了 10〜15 分×2。停滞は第2章でもう出るので、30 回は要らない。

**質問票**

1. **話は進んでいたか**（それぞれ）—「同じところを回っていた／ゆっくりだが進んでいた／よく進んでいた」
2. **同じことの繰り返しが気になったか**（それぞれ）—「何度も気になった／少し気になった／気にならなかった」＋あれば場所を自由記述
3. **急ぎすぎ・雑だと感じたか**（それぞれ）—「感じた（どこで）／感じなかった」
4. **主人公が、自分で決めて動いていると感じたか**（それぞれ）—「流されているだけ／ときどき／自分で動いている」
5. **どちらを続けて読みたいか** —「作品1／作品2／どちらでもない」（**判定に使う設問**）
6. 自由記述 —「どちらか一方にだけあった良い点・悪い点」

**判定**

- 設問5で 3人以上が B → 案1 を残す
- 3人以上が A → 案1 を戻す。設問3の記述を読み、速すぎたのか別の理由かを控える
- どちらも 3人に届かない → 差が示せていない。設問1・2で B が良く、設問3で B だけに「感じた」が 2人以上いれば、「状況を一つは動かす」の行を外した版でもう一度だけ試す。それでも割れたら戻す（文面は短いほうを採る）

### 5.2 案2（章の切り替え）

**材料**: 「続ける」**20 回**・**4 回ごとに**章を閉じる（5 章＝切り替えが 4 回）。切り替えの数を増やすため、章を短くする。

**質問票**

1. **場面が変わったとき、いつ・どこに居るかがすぐ分かったか**（それぞれ）—「何度か迷った／一度迷った／迷わなかった」
2. **日付・時間帯・曜日の食い違いに気づいたか**（それぞれ）—「気づいた（どこで）／気づかなかった」
3. **場面が変わるたびに、同じような始まり方だと感じたか**（それぞれ）—「感じた／少し／感じなかった」
4. **場面と場面のあいだが飛びすぎて、置いていかれたか**（それぞれ）—「置いていかれた（どこで）／大丈夫だった」
5. **どちらを続けて読みたいか** —「作品1／作品2／どちらでもない」（**判定に使う設問**）
6. 自由記述

作る側は、読者に渡さない控えとして、章ごとの「章の題の日付」と「本文に書かれた日付」を並べた表を A・B それぞれ作っておく（食い違いの数は人が数えられる事実で、読者の印象とは別に記録する）。

**判定**

- 設問5で 3人以上が B → 案2 を残す
- 3人以上が A → 戻す。設問4（飛びすぎ）が理由なら、(a) の「時か場所が変わった先の場面にする」だけを外した版を次の候補にする
- 割れた場合 → 控えの表で B の食い違いが A より明らかに少なく、設問4で B だけに「置いていかれた」が 2人以上いないなら残す（矛盾が減ること自体に価値があるため）。そうでなければ戻す

### 5.3 案3（レビューの成長欄）

**材料**: 「続ける」**30 回**・5 回ごとに章を閉じる（6 章）。効果は章を重ねるほど出るので、`実験_対照読み比べ.md` と同じ長さにする。**案1・案2 の採否が決まった後の `main`** を A とする。

**質問票**

1. **後半（終わりの3分の1）は、前半と比べてどうだったか**（それぞれ）—「同じことの繰り返しになった／変わらない／後半のほうが面白い」
2. **人物が一貫しているか**（それぞれ）—「途中で別人のようになった人物がいた／少し揺れたが同じ人物だと分かった／終始一貫していた」（`実験_対照読み比べ.md` の設問2と同文）
3. **人物が、物語の中で変わっていったと感じたか**（それぞれ）—「最初から最後まで同じことをしている／少し変わった／はっきり変わった」
4. **矛盾に気づいたか**（それぞれ）—「気づいた（場所・時間・出来事・人物の言動）／気づかなかった」
5. **どちらを続けて読みたいか** —「作品1／作品2／どちらでもない」（**判定に使う設問**）
6. 自由記述

作る側の控え: 最後の章の時点で【登場人物】に足されている「判明した設定」を A・B それぞれ全部書き出し、人が「事実」「行動の要約・人物評」「既存設定の言い換え」に分けて数える。

**判定**

- 設問5で 3人以上が B → 残す
- 3人以上が A → 戻す。設問2・4で B の矛盾が増えていたら、絞りすぎで必要な事実が落ちた疑い（控えで B の「事実」の件数が A より減っていないか見る）
- 割れた場合 → 控えで B の「行動の要約・人物評」が A の半分以下になっており、設問2・4で B が A より悪くなければ残す（system が太らないことの利が残るため）。そうでなければ戻す

## 6. このレビューの限界

- 読んだのは各条件 1 本ずつ。温度 0.9 なので、同じ条件でも別の回では出方が違う（特に B-S3-T14 の応答内の重複、A-S3 の「ランドセル」は1回きりの事故かもしれない）
- 本編のモデルは安価な 2 種だけ。高価なモデルでは §1.4（声のぶれ）や §1.6（説明過多）は軽くなる見込みだが、§1.1（文体ルールが停滞を指示している）と §1.3（時刻の食い違い）はプロンプトの構造から来るので、モデルを替えても残ると考えている。これも読み比べで確かめる対象
- 再現スクリプトはアプリではない（§0.2）。配線の違いで起きたこと（A 第6章の空の場面メモ）は所見から外した
- 弱点の原因は「と思われる箇所」であり、文面を変えて確かめてはいない。確かめるのが §5
