# 今後の機能のアイデア

まだ設計も計画もしていない、思いついた段階のメモ。採用するときは設計書か計画書へ移す。

## キャラクターを別の世界へ連れていくときの「順応」（2026-11-14）

気に入ったキャラクターを別の世界の物語でも使いたいとき、**その世界に合わせて設定を書き換える**機能。

- 例: 現代の学園で作った人物を、剣と魔法の世界へ連れていく。人柄・口調・関係の癖は残し、職業・持ち物・言葉づかいの時代感・外見の服装などを新しい世界に合わせる。
- 書き換えた結果は**元の素材を上書きせず、別の版として作る**のが自然そう（元の世界の物語でも使い続けられるように）。
- 背景: 起案の段階で人物を「どの世界にも持ち出せる性質」だけで書かせると、人物が空っぽになり、この世界での立場を書く場所も無くなる。そこで起案では固有名詞だけを避け、世界への合わせ込みは持ち出すときにやる、という分担にした（`決定記録.md` §14）。
